Landing Lab

Three landing pages I built from scratch. Kept in one repo because I got
tired of opening a new one for every small idea.

Everything here is static. Plain HTML, CSS, and JavaScript. No build step,
no framework, nothing to install.

Live: https://hamza-front.github.io/landing-lab/


Projects

ProGym

A gym landing page. Sticky navigation, hero with a call to action, classes
and trainers, pricing tiers, and a contact form that checks the input
before it lets you submit. Dark mode toggle, scroll reveals, smooth scroll
between sections. HTML, Tailwind via CDN, vanilla JS.

Live: https://hamza-front.github.io/landing-lab/progym/
Locally: open progym/index.html


Restaurant

A restaurant landing page in Arabic, right to left. Hero, a short story,
the menu, a few photos of the place, testimonials, location with hours and
a Google Maps link, and a closing call to action. Hand-written CSS with
design tokens. No libraries. No box-shadow anywhere, that was a deliberate
choice.

Live: https://hamza-front.github.io/landing-lab/restaurant/
Locally: open restaurant/index.html


Portfolio

A single-page showcase I designed for a video editor. Scroll-linked
animations, a sticky project stack, animated skill meters, and a radial
contact layout. The idea was to make the portfolio feel like a piece of
editing itself, not just a page listing work.

Live: https://hamza-front.github.io/landing-lab/Portfolio/
Locally: open Portfolio/index.html


Running anything

Nothing to install.

    git clone https://github.com/hamzaebrahim809-blip/Landing-Lab.git
    cd Landing-Lab

Open index.html in your browser. The root one links to all three. Or jump
straight into a folder. If you want auto-reload while editing, Live Server
in VS Code works well.
