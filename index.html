LANDING.LAB
three projects, one repo, zero build steps

مساحة صغيرة أجمع فيها كل صفحة هبوط أبنيها.

ثلاث صفحات، كل واحدة لها مجلدها الخاص. نفس التقنية في الثلاث: HTML و CSS و JavaScript عادي. لا فريمورك، لا أدوات بناء، لا شيء يحتاج تثبيت.

شوف المشاريع ليش هذا كله
~/landing-lab
$ tree . ├── progym/ # gym landing page ├── restaurant/ # arabic restaurant, RTL └── Portfolio/ # video editor showcase $

الفكرة

01 / about
LL

بدأت Landing Lab لأني تعبت من فتح مستودع جديد لكل صفحة صغيرة. كل فكرة كانت تصير رابط منفصل، ومجلد منفصل، و README منفصل. صارت عندي فوضى أكثر من اللازم.

الحل كان بسيط: مجلد واحد، كل المشاريع تحته، كل مشروع في مساره. تقدر تفتح أي واحد مباشرة، أو تشوف الكود كله في مكان واحد.

ما فيه أدوات بناء. ما فيه npm install. ما فيه شيء يشتغل في الخلفية. تفتح index.html وكل شيء شغّال.

03 / process
1

مجلد جديد

أنشئ مجلد باسم المشروع داخل الجذر. كل مشروع له مساره الخاص، لا شيء يتداخل مع شيء آخر.

2

index.html وملفاته

أبني الصفحة بـ HTML و CSS و JavaScript عادي. لو احتاجت صورة أو ملف إضافي، يكون داخل مجلد المشروع نفسه.

3

سطر واحد هنا

أفتح index.html الجذري وأضيف بطاقة للمشروع الجديد. الجذر يبقى مجرد فهرس، لا يحتوي على كود المشاريع نفسها.

4

نشر

دفعة واحدة إلى main. GitHub Pages يتولى الباقي. لا شيء يحتاج بناء، الفروع الأخرى للعمل الجانبي فقط.

لو عندك فكرة صفحة، تقدر تشاركني فيها.

أرد عادة في غضون يوم. البريد أسرع، لكن GitHub أيضًا يوصلني بسرعة.
